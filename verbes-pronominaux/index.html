À retenir

Exemple : se lever

jeme suis levé(e)
tut'es levé(e)
il / elles'est levé / levée
nousnous sommes levé(e)s
vousvous êtes levé(e)s
ils / ellesse sont levés / levées

Les règles

1. Toujours avec être : pronom + être + participe.

2. Le participe s'accorde avec le sujet : fille +e, garçons +s, filles +es.

3. Négation : ne + pronom + être + pas + participe.

4. Participes irréguliers : assis, mis, tu, souvenu, inscrit, enfui, plaint, aperçu.
